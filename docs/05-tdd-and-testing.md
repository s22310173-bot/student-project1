# TDD and Testing

## Issue Tested

Input Validation

### RED

Test dibuat terlebih dahulu dan gagal.

Contoh:

Expected:
Question tidak boleh kosong.

Result:
FAIL

### GREEN

Validasi ditambahkan ke fungsi saveQuestion().

Result:
PASS

### REFACTOR

Kode validasi dirapikan dan dokumentasi diperbarui.

- Answer Question berhasil.
