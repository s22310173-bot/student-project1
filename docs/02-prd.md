# Product Requirements Document

## Product Name

QuizFlow

## Product Overview

QuizFlow adalah aplikasi kuis sederhana yang memungkinkan pembuatan soal dan pelaksanaan kuis secara langsung di browser.

## Goals

- Membuat kuis dengan mudah.
- Menjawab soal secara interaktif.
- Menampilkan nilai mahasiswa.

## Core Features

1. Create Question
2. Start Quiz
3. Answer Questions
4. View Quiz Result
5. Input Validation

## Success Criteria

- Soal berhasil dibuat.
- Kuis dapat dijalankan.
- Nilai dapat dihitung otomatis.
- Validasi input berjalan.

## Out of Scope

- Login pengguna
- Database online
- Ranking peserta
- Timer ujian
- Upload gambar
