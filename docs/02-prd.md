# Product Requirements Document

## Product Overview

Student Task Tracker adalah aplikasi web yang membantu mahasiswa mengelola tugas dengan cepat dan sederhana.

## Goals

- Membantu pengguna mencatat tugas.
- Membantu pengguna melacak status tugas.

## Non Goals

- Login pengguna.
- Database online.
- Kolaborasi antar pengguna.

## Target Users

- Mahasiswa
- Pelajar

## User Stories

- Sebagai mahasiswa saya ingin menambahkan tugas agar tidak lupa.
- Sebagai mahasiswa saya ingin melihat daftar tugas agar mengetahui pekerjaan yang harus dilakukan.
- Sebagai mahasiswa saya ingin menandai tugas selesai agar dapat memantau progres.

## Core Features

1. Tambah tugas.
2. Lihat daftar tugas.
3. Tandai selesai.
4. Hapus tugas.
5. Validasi input.

## Acceptance Criteria

- Tugas baru muncul setelah ditambahkan.
- Tugas dapat dihapus.
- Tugas dapat ditandai selesai.
- Input kosong ditolak.

## Success Criteria

- Semua fitur berjalan tanpa error.
- Pengguna dapat mengelola tugas dengan mudah.

## Risks

- Data hilang saat halaman direfresh.

## Out of Scope

- Login.
- Database.
- Sinkronisasi cloud.
