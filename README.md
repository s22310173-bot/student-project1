# QuizFlow

## Description

QuizFlow adalah aplikasi kuis sederhana berbasis web yang memungkinkan dosen membuat soal dan mahasiswa mengerjakan kuis serta melihat nilai.

## Features

1. Create Question
2. Start Quiz
3. Answer Questions
4. View Quiz Result
5. Input Validation

## Technology

- HTML
- CSS
- JavaScript
- Jest

## Running the Project

1. Buka folder project.
2. Jalankan menggunakan Live Server.
3. Buat soal.
4. Masukkan nama mahasiswa.
5. Mulai kuis dan lihat hasil.
